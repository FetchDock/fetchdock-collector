# Security Policy

The collector receives reports that users chose to share, so please **don't open a public issue** for a vulnerability.

## Reporting a vulnerability
Use [GitHub's private vulnerability reporting](https://github.com/FetchDock/fetchdock-collector/security/advisories/new). Include the steps to reproduce it and what an attacker could reach (report contents, instance secrets, maintainer access).

## Supported versions
Only the version deployed at https://reports.fetchdock.dev, built from the latest release, is supported.
